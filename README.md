# ABループプレイヤー

動画のA点〜B点の間をループ再生できる、Windows用のシンプルな動画プレイヤーです。

## ダウンロードと起動

- `ABLoopPlayer.exe` と `ABLoopPlayer.exe.config` を同じフォルダに置いて、exeをダブルクリックで起動
- 追加のインストールは不要です（Windows 10 / 11 標準の .NET Framework 4.8 / WPF で動作）

## 使い方

1. 「ファイルを開く」ボタン、または動画ファイルをウィンドウへドラッグ＆ドロップ
2. ループ開始位置で「Aを設定」、終了位置で「Bを設定」すると自動でABループが始まります
3. A/Bは ±0.1秒ボタンで微調整できます

## 機能

- AB区間ループ（シークバー下にA・Bマーカーと区間を表示、ループ回数カウント）
- 再生速度変更（0.25x 〜 2.0x）
- 音量調整、全画面表示
- ショートカットキー
  - Space: 再生 / 一時停止
  - ← / →: 5秒移動（Shift同時押しで1コマ移動）
  - A / B: A点・B点を設定
  - L: ループ ON / OFF
  - ↑ / ↓: 速度変更
  - F: 全画面、Esc: 全画面終了

## 対応形式

Windows標準コーデックで再生できる形式（mp4 など）。mkv等は環境のコーデック次第で再生できない場合があります。

## その他

- `ABLoopPlayer.html` + `ABLoopPlayer.bat`: ブラウザ（Edgeアプリモード）で動くWeb版
- `MainWindow.cs` / `ABLoopPlayer.csproj`: ソースコード（XAMLなし、C#のみのWPFアプリ）
